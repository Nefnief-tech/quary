# Web SPA (Phase 1)

SvelteKit + Tailwind + xterm.js. Scaffolded in Phase 1 with the minimal admin and user areas.

Planned split: `/` routes for the user panel (their servers, console, files, backups, schedules, subusers, API keys), `/admin` routes for the admin panel (nodes, users, runners, modules, settings, audit log), gated by permissions on both the UI and the API.
