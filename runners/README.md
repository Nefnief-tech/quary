# Runners (Phase 1)

Declarative runner definitions (Vanilla, Paper, Fabric first; Purpur, Folia, Quilt, Forge, NeoForge, Velocity, BungeeCord later) plus admin-added custom runners via YAML.

See `docs/ARCHITECTURE.md` for the `Runner` interface. Upstream sources: Mojang version manifest, PaperMC API, Fabric meta, Forge/NeoForge maven metadata. Artifacts are checksum-verified and cached per runner/version/build on the node.
